# Reports 每周周报

本文件夹用于存放 Stage 1 阶段每周学习与实验进展报告。

周报主要按照实验室要求进行整理，内容包括：

1. 基本信息；
2. 本周推进内容；
3. 本周最重要的实际产出；
4. 本周关键实验结果；
5. 本周主要问题与解决尝试；
6. 下周计划。

周报用于记录每周课程学习、代码实验、问题解决和阶段性成果，便于后续组会汇报和 Stage 1 阶段性材料提交。

目前 Week 01 周报主要围绕吴恩达 Machine Learning Specialization 中的两个实践实验展开：

- Practice Lab: Linear Regression
- Practice Lab: Logistic Regression

这两个实验分别对应监督学习中的回归任务和分类任务，是后续学习神经网络、深度学习和图像分类任务的基础。
