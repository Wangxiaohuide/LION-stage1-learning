# Reports 每周周报

本文件夹用于存放 Stage 1 阶段每周学习与实验进展报告。

周报主要按照实验室要求进行整理，内容包括：

1. 基本信息；
2. 本周推进内容；
3. 本周最重要的实际产出；
4. 本周关键实验结果；
5. 本周主要问题与解决尝试；
6. 下周计划。

## 周报用途

周报用于记录每周课程学习、代码实验、问题解决和阶段性成果，便于后续组会汇报和 Stage 1 阶段性材料提交。

目前周报主要围绕 CS229 与机器学习实践实验展开：

- Practice Lab: Linear Regression
- Practice Lab: Logistic Regression
- Neural Networks for Binary / Multiclass Classification
- CS229 PS4: Independent Component Analysis

这些内容覆盖了监督学习、神经网络、无监督学习与强化学习的阶段性学习记录，便于后续复盘课程概念、实验代码和个人理解变化。
