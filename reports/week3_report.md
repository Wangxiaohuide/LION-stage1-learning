## 二、无监督学习内容总结

### 1. K-means 聚类

K-means 的目标是在没有标签的情况下，把样本划分成若干个簇。它的基本流程是：

1. 初始化 `K` 个聚类中心；
2. 将每个样本分配给距离最近的中心；
3. 根据分配结果重新计算每个簇的中心；
4. 重复直到聚类结果基本稳定。

我对 K-means 的理解是：它不是在学习“正确答案”，而是在根据距离度量寻找数据内部的相似性结构。它适合处理簇形状比较规则、距离定义比较可靠的问题，但也会受到初始中心、特征尺度和 `K` 的选择影响。

### 2. 混合高斯模型与 EM

Gaussian Mixture Model（GMM）可以看作比 K-means 更柔性的聚类方式。K-means 通常给每个样本一个硬分配，而 GMM 会给出样本属于每个高斯分布的概率。

EM 算法的思想可以概括为：

- E-step：根据当前参数估计隐变量的后验概率；
- M-step：根据隐变量估计结果重新更新模型参数。

这部分让我意识到，无监督学习中很多问题的困难在于存在看不见的隐变量。EM 的思路不是一次性直接求解，而是在“估计隐变量”和“更新参数”之间反复迭代。

### 3. ICA 与潜在因素分离

ICA 的目标是从混合观测中恢复相互独立的潜在信号。本周的鸡尾酒会实验正是这个思想的代码实践。

如果观测到的混合信号为：

```text
X = A S
```

其中 `S` 是原始独立声源，`A` 是未知混合矩阵，那么 ICA 希望学习一个解混矩阵 `W`，使得：

```text
S ≈ X W^T
```

这个实验让我真正理解到，无监督学习并不只是“没有标签的分类”，它还可以用于发现数据背后的独立生成因素。

## 三、强化学习内容总结

强化学习的基本框架包括：

- agent：智能体；
- environment：环境；
- state：状态；
- action：动作；
- reward：奖励；
- policy：策略；
- value function：价值函数。

和监督学习不同，强化学习通常没有现成的正确标签。智能体需要在环境中采取动作，根据奖励信号不断调整策略。一个动作的好坏也不一定能立刻判断，因为当前动作可能影响未来很多步的收益。

我目前对强化学习最重要的理解是：它优化的不是单次预测是否正确，而是长期累计回报。也就是说，强化学习更关注序列决策问题。

## 四、ICA 鸡尾酒会实验记录

### 1. 实验任务

本次实验使用 CS229 PS4 中的 `mix.dat`。数据包含 5 路混合音频，每一路都是多个原始声源的线性混合。实验目标是学习一个矩阵 `W`，把混合音频分离成相互独立的声源。

我在仓库中整理了实验代码：

```text
week3task/task05_ica_cocktail_party/src/p04_ica.py
```

### 2. 核心代码

本次主要补全 `update_W` 和 `unmix`。

`update_W` 中使用 Laplace 分布假设，对 `W` 做随机梯度上升：

```python
source_estimate = W.dot(x)
gradient = np.linalg.inv(W.T) - np.outer(np.sign(source_estimate), x)
updated_W = W + learning_rate * gradient
```

`unmix` 则使用学到的 `W` 对所有混合信号做解混：

```python
S = X.dot(W.T)
```

### 3. 代码理解

这段实现让我把 ICA 的公式和代码联系起来：

- `W.dot(x)` 表示当前估计出的独立声源；
- `np.sign(W.dot(x))` 来自 Laplace 分布的梯度；
- `np.linalg.inv(W.T)` 来自 log determinant 项；
- `np.outer(...)` 把单个样本的更新写成矩阵梯度；
- `X.dot(W.T)` 是把整个混合信号矩阵一次性分离。

相比前两周的分类实验，这次代码量更少，但数学含义更集中。尤其是 log determinant 和概率分布假设对梯度的影响，还需要后续继续复习。
