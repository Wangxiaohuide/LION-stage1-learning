### 2.2 逻辑回归实验

逻辑回归实验用于解决二分类问题。该实验包含两个部分：

1. 普通逻辑回归；
2. 正则化逻辑回归。

普通逻辑回归部分主要学习如何使用 sigmoid 函数将线性模型输出转化为概率，并根据概率完成二分类判断。

逻辑回归模型可以理解为：

```text
先计算 z = w · x + b
再通过 sigmoid 函数把 z 转换成 0 到 1 之间的概率

其中 sigmoid 函数为：

g(z) = 1 / (1 + e^(-z))

如果模型输出值大于等于 0.5，通常预测为类别 1；如果输出值小于 0.5，通常预测为类别 0。

4. 本周关键实验结果
4.1 数据集

线性回归实验中，数据集包含 97 个训练样本：

x_train.shape = (97,)
y_train.shape = (97,)
m = 97

其中：

x_train：城市人口，单位为 10,000 人；
y_train：餐厅利润，单位为 10,000 美元。

如果利润为负数，表示该城市中餐厅处于亏损状态。

逻辑回归实验中，输入数据包含两个特征和一个二分类标签：

x_train：二维输入特征；
y_train：分类标签，取值为 0 或 1。
4.2 模型

线性回归模型为：

f(x) = wx + b

该模型用于预测连续数值，例如餐厅利润。

逻辑回归模型可以表示为：

f(x) = sigmoid(w · x + b)

其中 sigmoid 函数为：

sigmoid(z) = 1 / (1 + e^(-z))

逻辑回归输出值在 0 到 1 之间，可以理解为样本属于正类的概率。

4.3 指标与函数

线性回归中的代价函数用于衡量预测值与真实值之间的整体误差。实验中实现了 compute_cost() 函数，用于计算当前参数 w 和 b 下模型预测结果与真实标签之间的差距。

线性回归代价函数可以简单理解为：

先计算每个样本的预测误差
再对误差进行平方
最后求整体平均误差

逻辑回归中的代价函数用于衡量分类预测结果与真实标签之间的差异。当真实标签为 1 时，希望模型输出尽量接近 1；当真实标签为 0 时，希望模型输出尽量接近 0。如果模型预测错误，代价函数会变大。

正则化逻辑回归在普通逻辑回归代价函数的基础上加入正则项，用于限制模型参数过大，从而减少过拟合风险。

4.4 变化

在线性回归实验中，通过梯度下降更新参数 w 和 b。随着迭代进行，代价函数逐渐下降，说明模型预测误差在减小。

线性回归中的参数更新可以简单理解为：

w = w - 学习率 × w方向的梯度
b = b - 学习率 × b方向的梯度

在逻辑回归实验中，同样使用梯度下降学习模型参数。模型通过不断调整权重和偏置，使分类结果逐渐接近真实标签。

普通逻辑回归适合较简单的线性分类场景；正则化逻辑回归通过引入正则项，可以在拟合复杂边界的同时控制模型复杂度，从而减少过拟合。

问题 2：线性回归代价函数实现错误

在实现 compute_cost() 时，曾出现测试错误：

Cost must be 2 but got 16.0

原因是只累加了所有样本的误差平方，但忘记最后除以 2m。

解决方法是在函数末尾加入：

total_cost = total_cost / (2 * m)

修改后测试通过。

问题 3：线性回归梯度函数测试不通过

在实现 compute_gradient() 时，最初对函数参数和全局变量的区别理解不清楚，可能误用了 x_train、y_train。

解决方法是统一使用函数传入的参数 x 和 y：

f_wb = w * x[i] + b

而不是直接使用外部变量。

修改后梯度函数测试通过。

问题 4：逻辑回归中 sigmoid 函数理解不清楚

一开始不理解为什么逻辑回归要使用 sigmoid 函数。

通过实验理解到，sigmoid 函数可以将线性输出 z = w · x + b 压缩到 0 到 1 之间，因此可以表示样本属于正类的概率。

当输出值大于等于 0.5 时，可以预测为类别 1；当输出值小于 0.5 时，可以预测为类别 0。

问题 5：正则化逻辑回归较难理解

正则化部分相比普通逻辑回归更抽象，尤其是为什么代价函数要加上参数平方项。

通过实验初步理解到，正则化项可以限制参数过大，使模型边界不过度复杂，从而减少过拟合。

正则化不是让模型变简单到无法学习，而是在拟合数据和控制复杂度之间取得平衡。
