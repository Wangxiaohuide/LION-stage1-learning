# LION Stage 1 课程学习与基础实现

## 一、阶段目标

本仓库用于记录 Stage 1 阶段的课程学习、基础代码实现、实验日志与图表结果。

Stage 1 的主要目标是学习机器学习与计算机视觉基础课程，并完成基础算法和图像分类实验，为后续论文阅读与项目复现打基础。

## 二、阶段要求

- 课程学习记录与知识总结
- 至少 5 个基础代码任务
- 在 MNIST、Fashion-MNIST 或 CIFAR-10 上完成分类训练
- 可运行的代码仓库、日志与图表
