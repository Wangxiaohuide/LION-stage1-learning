3. 线性回归模型

单变量线性回归模型可以写成：

f(x) = wx + b

其中：

x：输入特征，本实验中表示城市人口；
y：真实标签，本实验中表示餐厅利润；
w：权重参数，也可以理解为直线斜率；
b：偏置参数，也可以理解为直线截距；
f(x)：模型对利润的预测值。

本实验的核心目标是找到合适的 w 和 b，使模型预测的利润尽可能接近真实利润。

简单来说，就是用一条直线去拟合城市人口和餐厅利润之间的关系。

4. 代价函数

为了衡量当前模型预测得好不好，需要定义代价函数。

代价函数的作用是：

衡量模型预测值和真实值之间的整体差距

在本实验中，代价函数的计算过程可以理解为：

1. 对每一个训练样本计算预测值；
2. 计算预测值和真实值之间的误差；
3. 对误差进行平方；
4. 把所有样本的误差平方加起来；
5. 再除以 2m，得到平均意义上的整体误差。

代价函数越小，说明模型预测越接近真实数据；代价函数越大，说明预测误差越大。

5. compute_cost 函数实现

实验中需要实现 compute_cost() 函数，用于计算当前参数 w 和 b 下的代价函数值。

核心代码如下：

for i in range(m):
    f_wb = w * x[i] + b
    cost = (f_wb - y[i]) ** 2
    total_cost += cost

total_cost = total_cost / (2 * m)

这段代码的含义是：

for i in range(m)：遍历所有训练样本；
f_wb = w * x[i] + b：计算第 i 个样本的预测利润；
cost = (f_wb - y[i]) ** 2：计算预测值和真实值之间的误差平方；
total_cost += cost：把每个样本的误差累加；
total_cost = total_cost / (2 * m)：求整体代价函数。

一开始我出现过测试错误，原因是忘记最后除以 2m。修改后，测试通过。

6. 梯度下降

梯度下降用于自动寻找较优的参数 w 和 b。

直观理解：

代价函数表示模型误差。
梯度表示当前参数应该往哪个方向调整，才能让误差变小。
梯度下降就是不断根据梯度调整参数，让代价函数逐渐下降。

参数更新可以简单理解为：

w = w - 学习率 × w方向的梯度
b = b - 学习率 × b方向的梯度

其中：

学习率决定每次参数更新的步长；
学习率太大，可能导致训练不稳定；
学习率太小，训练速度会比较慢。
7. compute_gradient 函数实现

实验中需要实现 compute_gradient() 函数，用来计算梯度下降中需要的两个梯度。

核心代码如下：

for i in range(m):
    f_wb = w * x[i] + b
    dj_dw = dj_dw + (f_wb - y[i]) * x[i]
    dj_db = dj_db + (f_wb - y[i])

dj_dw = dj_dw / m
dj_db = dj_db / m

其中：

dj_dw 表示代价函数对 w 的梯度；
dj_db 表示代价函数对 b 的梯度。

这两个值用于指导参数更新方向。

这一部分我需要注意的是：函数内部应该使用传入的参数 x 和 y，不能直接使用外部变量 x_train 和 y_train。否则测试函数传入其他数据时，结果会出错。

8. 批量梯度下降

本实验后面使用批量梯度下降来训练模型参数。

这里的“批量”指的是：

每次更新参数时，使用全部训练样本来计算梯度。

如果 compute_cost() 和 compute_gradient() 写对，并且学习率选择合适，那么代价函数应该随着迭代逐渐下降。

通过运行实验，可以看到模型参数逐步更新，最终得到一条能够较好拟合数据的直线。
